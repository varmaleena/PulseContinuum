# Devpost fields

Project name: **PulseContinuum AI**

Elevator pitch:

AI-powered post-discharge coordination that keeps patient evidence, caregiver responses, and clinician handoffs connected—escalating unanswered tasks without losing context.

## Built with

Next.js, React, TypeScript, Python, FastAPI, Pydantic, Boto3, Amazon Bedrock, Amazon Nova Pro, AWS Lambda, Amazon DynamoDB, Amazon S3, Amazon SES, Amazon EventBridge, Amazon SQS, Amazon CloudWatch, AWS CDK, CSS

## Try it out

- Live application: https://pulsecontinuum.vercel.app
- Source repository: https://github.com/varmaleena/PulseContinuum

## Gallery order and captions

1. Care overview — Three tested synthetic stories provide an immediate judge entry point.
2. Patient workbench — Evidence and the written discharge context stay attached to one episode.
3. Accountable coordination — Owned tasks, deadline escalation and persistent concerns remain visible.
4. Doctor handoff — A generated packet documents evidence and pending work; it is not proof of treatment or email delivery.
5. Engineering view — Inspect the episode graph and bounded workflow stages.
6. AWS telemetry — Distinguish recorded AWS evidence, current service calls and simulated communication events.
